# Excel-Dashboard
This project demonstrates a complete end-to-end data analytics workflow using Microsoft Excel. It includes a dynamic dashboard that visualizes regional sales performance, helping track daily targets and measure efficiency across multiple sales executives.



📊 Dataset Overview

**RAW DATA** — contains detailed sales records, including:

Employee Code and Sales Executive Name

Region (e.g., Mumbai, Delhi, Nagpur, Chennai, Pune)

Daily sales figures (Day 1–Day 5)

Total Sales, Target, Target Hit %, and Away From Target %



**DASHBOARD** — includes summarized and visualized data such as:

Top performers by Total Sales

Target achievement leaderboard

Comparison by “Away From Target %”

Interactive charts and slicers for quick insights



🎯 Key Insights

Sales executives are ranked based on Total Sales and Target Hit %.

The dashboard allows users to identify top-performing regions and employees at a glance.


**Tools and Features Used**

Microsoft Excel (.xlsm) with macros and slicers

Pivot Tables and Charts

Data Cleaning and Transformation

KPI Calculations

Dynamic Dashboard Layout and Conditional Formatting
